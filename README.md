# gameweave-legal

Public mirror of legal documents and account-control instructions for the **GameWeave** Android app.

This repository exists solely to host the privacy policy, terms of service, and account deletion instructions at public URLs via GitHub Pages — the GameWeave source code lives in a separate private repository.

## Live URLs

- Landing: <https://brayskiy.github.io/gameweave-legal/>
- Privacy Policy: <https://brayskiy.github.io/gameweave-legal/privacy.html>
- Terms of Service: <https://brayskiy.github.io/gameweave-legal/terms.html>
- Account Deletion: <https://brayskiy.github.io/gameweave-legal/delete-account.html>

## Editing

The canonical text lives as Markdown in the private GameWeave repository's `docs/legal/` folder. The HTML files here are mirrored from those sources whenever the legal text changes.
